# Phases.fm

A modern single-page podcast site built with Svelte 5, Vite, and [Media Chrome](https://www.media-chrome.org/).

## Development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run check
npm run build
```

The current 22-episode catalog is sourced from the official Transistor RSS feed. Podcast destinations and the Kit newsletter form use the official Phases accounts/form.
