# SEO/AEO experiment ideas

- Add topic hubs only when the episode catalog supports useful non-duplicative collections (ADHD, neurodiversity, behavior, school, parent wellbeing); define a stable editorial taxonomy rather than keyword-match pages.
- Add transcript sections only if publisher-approved transcripts become available; never generate or infer them from summaries.
- Measure deployed search landing pages and referrers in Plausible after enough post-deploy time; treat this as delayed evidence, not an iteration benchmark.
