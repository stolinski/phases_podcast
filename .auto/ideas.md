# SEO/AEO experiment ideas

- Add first-party episode detail routes with stable slugs derived from episode number/title and PodcastEpisode JSON-LD.
- Add XML sitemap and robots.txt generated from the live RSS catalog.
- Add site-wide canonical, Open Graph, Twitter card, Organization, WebSite, and PodcastSeries metadata.
- Add Dr. Courtney Person expertise schema and connect her as host/author of episode entities.
- Preserve structured RSS description content (paragraphs, lists, and links) instead of flattening everything to one paragraph, using a strict sanitizer.
- Add topic hubs only when the episode catalog supports useful non-duplicative collections (ADHD, neurodiversity, behavior, school, parent wellbeing).
- Add faithful key-takeaway or question sections from publisher-authored show notes; never infer unsupported medical advice.
- Measure deployed search landing pages and referrers in Plausible after enough post-deploy time; treat this as delayed evidence, not an iteration benchmark.
